Consultoria em Desenvolvimento Projeto desenvolvido para a disciplina de C# Development (FIAP). 
Descrição Sistema web de consultoria onde o cliente pode visualizar problemas disponíveis e solicitar uma solução.
Funcionalidades: 
- Listagem de serviços/problemas
- Solicitação com nome e email
- Painel administrativo
- Aprovação/Reprovação de pedidos
Tecnologias Utilizadas: - ASP.NET Core MVC - C# - Bootstrap - HTML/CSS
Feito por: - Enzo Barbeli (RM: 554272) - Felipe Santana (RM: 554259)

 Como Executar:
1. Clonar o repositório
2. Abrir no Visual Studio
3. Executar o projeto (F5)
